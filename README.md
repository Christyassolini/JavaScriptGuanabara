# 📚 Curso Básico de JavaScript

Este repositório contém todo o conteúdo desenvolvido durante meu **Curso Básico de JavaScript**, onde construí uma base sólida na linguagem, aprendendo desde seus fundamentos até a manipulação do DOM com diversos exercícios práticos.

O objetivo deste repositório é documentar minha evolução, prática e consolidação dos conceitos essenciais para o desenvolvimento com JavaScript.

---

## 🧠 Fundamentos da Linguagem

Neste módulo estudei:

- A origem do JavaScript
- Sua evolução ao longo do tempo
- O paradigma client-server
- A expansão da linguagem para o back-end com Node.js

Compreender essa base foi essencial para entender o papel do JavaScript no desenvolvimento web moderno.

---

## 📦 Variáveis e Tipos de Dados

Aprendi:

- Como declarar variáveis
- Como armazenar dados corretamente
- Como o JavaScript trata os tipos primitivos
- A tipagem dinâmica da linguagem

Esse conhecimento é fundamental para estruturar qualquer aplicação.

---

## ➕ Operadores

Estudo e prática com:

- Operadores aritméticos
- Operadores lógicos
- Operadores relacionais

Foram realizados diversos exercícios práticos para reforçar a lógica e fixar o conteúdo.

---

## 🔀 Estruturas Condicionais

Trabalhei com:

- `if` simples
- `if` aninhado
- `switch`

Aplicando muitos exercícios para desenvolver o raciocínio lógico e a tomada de decisões no código.

---

## 🔁 Estruturas de Repetição

Estudo das principais estruturas de loop:

- `while`
- `do while`
- `for`

Com vários exercícios práticos voltados para automação e repetição de tarefas.

---

## 🗂️ Arrays (Variáveis Compostas)

Módulo dedicado ao estudo de:

- Conceito de arrays

- Organização e iteração de dados

Sempre com foco em prática e resolução de exercícios.

## 🔧 Functions

Compreendendo que funções são essenciais para escrever código limpo, modular e eficiente.

- Como funciona a comunicação entre HTML, CSS e JavaScript
- Como capturar dados de formulários
- Como manipular elementos da tela
- Como alterar conteúdos dinamicamente
- Como integrar comportamento e interface

Foram realizados muitos exercícios práticos para consolidar o aprendizado.
